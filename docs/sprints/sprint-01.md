## Risks

- **Agentforce availability in a free org (OI-04).** It may need features the Developer Edition doesn't include. Mitigation: check on day one.
- **Plan sharing in the agent's context.** AC-01 and AC-02 must run as the user, so the Apex managed sharing from v1.1 has to hold. Mitigation: test as the new-hire demo user, not as the admin.
